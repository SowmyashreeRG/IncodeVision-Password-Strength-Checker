Password Strength Checker

About the Project

The Password Strength Checker is a Python-based cybersecurity project developed as part of the IncodeVision Cyber Security Internship.

It evaluates a password using basic security criteria and classifies its strength as Weak, Medium, or Strong. It also provides suggestions to help users improve password strength.

Features

- Checks password length.
- Detects uppercase and lowercase letters.
- Checks for numeric digits.
- Detects special characters.
- Classifies passwords as Weak, Medium, or Strong.
- Provides suggestions for improving password strength.
- Hides password input in the terminal.

Technologies Used

- Python
- Regular Expressions ("re")
- "getpass" module

Requirements

- Python 3 installed.
- No additional package installation is required.

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code or a terminal.
3. Run the following command:

python password_checker.py

4. Enter a test password when prompted.
5. Review the strength classification and improvement suggestions.

Testing

The program was tested with weak, medium, and strong example passwords.

Disclaimer

This project is intended for educational purposes. It uses basic password rules and does not guarantee protection against password-guessing attacks.
